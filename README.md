# بطاقة سعود السبيعي

بطاقة تعريف رقمية تُفتح من قطعة NFC: بطاقة معلّقة تتأرجح وتنقلب، رقم واتساب، زر «أضفني لجهات الاتصال»، انستقرام، وأعمالي.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة كاملة (بدون أي مكتبات خارجية غير خطوط Google) |
| `saud.vcf` | جهة الاتصال اللي تنحفظ لما يضغط الزائر «أضفني لجهات الاتصال» |
| `vercel.json` | يخلي Vercel يرسل ملف جهة الاتصال بالنوع الصحيح عشان الجوال يفتحه كجهة اتصال |

## النشر

المشروع ثابت (Static) وما يحتاج Build. في Vercel: **Add New → Project → Import** هذا المستودع، واترك الإعدادات الافتراضية (Framework: Other)، ثم أضف الدومين من **Settings → Domains**.

## تعديل البيانات

- الاسم والرقم والأعمال داخل `index.html`.
- لو تغيّر الرقم، عدّله في `index.html` وفي `saud.vcf`.
